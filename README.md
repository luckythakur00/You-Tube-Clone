#🎬 YouTube Clone
A fully functional YouTube Clone built with React.js, Tailwind CSS, and Context API for seamless state management. The app boasts a sleek, responsive UI, real-time notifications via React-Toastify, and dynamic icons powered by React-Icons. It fetches real-time YouTube data using RapidAPI, ensuring fresh and engaging content.

🚀 Live Demo: https://lucky-you-tube-clone.netlify.app

✨ Features
✅ Modern UI: Built with Tailwind CSS for a sleek and responsive design.
✅ Dynamic Content: Fetches real-time YouTube data via RapidAPI.
✅ State Management: Uses Context API for efficient state handling.
✅ Real-time Notifications: Integrated React-Toastify for a better user experience.
✅ Polished UI: Utilizes React-Icons for a visually appealing interface.

🛠️ Tech Stack
Frontend: React.js, Tailwind CSS
State Management: Context API
Notifications: React-Toastify
Icons: React-Icons
API: RapidAPI
